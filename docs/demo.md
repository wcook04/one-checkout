# One Checkout demo

Run the disposable terminal example from the source root:

```sh
python3 scripts/demo.py --human --compare-git
```

Read the [evaluation guide](evaluate.md#demonstration-evidence) for setup,
claim-to-evidence checks, installation rehearsal and their limits. Watch the
[One Checkout walkthrough](https://www.youtube.com/watch?v=MHBxGPLDqt4) for the
selected-fix and staging-handoff explanation.
